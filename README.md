# Smart Streetlight Admin Dashboard

## Run it
1. Install Node.js (LTS) from https://nodejs.org
2. In this folder: `npm install`
3. Start: `npm run dev`
4. Open the address shown (usually http://localhost:5173)
5. Sign in with admin@streetlight.com / admin123

Step 1 uses simulated data. Firebase arrives in Steps 2 and 3.
